# Уют&Ремонт — сайт компании по ремонту квартир

Статический сайт на GitHub Pages с формой заявок, отправляющей данные в Telegram-бот.

## 🚀 Сайт

После включения GitHub Pages сайт будет доступен по адресу:
**https://vlapetrushkin-dot.github.io/remont-site/**

## ⚙️ Как включить GitHub Pages (2 клика)

1. Откройте вкладку **Settings** этого репозитория
2. Слева выберите **Pages**
3. В блоке *Build and deployment* выберите:
   - **Source:** Deploy from a branch
   - **Branch:** `main` / `/ (root)`
4. Нажмите **Save** — через 1–2 минуты сайт будет доступен по ссылке выше

## 🤖 Как подключить Telegram-бот к форме

Заявки с формы отправляются напрямую в ваш Telegram через Bot API. Настройка занимает 3 минуты:

### Шаг 1. Создать бота через @BotFather

1. Откройте в Telegram: [@BotFather](https://t.me/BotFather)
2. Отправьте команду `/newbot`
3. Придумайте имя бота (например, «Уют Ремонт Заявки»)
4. Придумайте username бота — обязательно заканчивается на `bot` (например, `uyut_remont_bot`)
5. BotFather пришлёт вам **токен** вида:
   ```
   7123456789:AAHdqTcvCH1vGWJxfSeofSAs0K5PALDsaw
   ```
   Скопируйте его — он нужен на шаге 3.

### Шаг 2. Узнать свой chat_id

1. Найдите в Telegram [@userinfobot](https://t.me/userinfobot) и нажмите **Start**
2. Бот пришлёт ваш ID вида `123456789` — скопируйте его
3. **Важно:** найдите своего только что созданного бота (по имени из шага 1) и нажмите **Start** — иначе бот не сможет вам писать

### Шаг 3. Вставить токен и chat_id в код

1. Откройте файл `index.html` в этом репозитории
2. Нажмите на карандаш (✏️ Edit)
3. Найдите строки (используйте Ctrl+F по слову `TG_BOT_TOKEN`):
   ```js
   const TG_BOT_TOKEN = '';
   const TG_CHAT_ID   = '';
   ```
4. Вставьте свои значения:
   ```js
   const TG_BOT_TOKEN = '7123456789:AAHdqTcvCH1vGWJxfSeofSAs0K5PALDsaw';
   const TG_CHAT_ID   = '123456789';
   ```
5. Внизу страницы нажмите **Commit changes** → **Commit changes**

Через 1–2 минуты сайт обновится, и все новые заявки будут приходить вам в Telegram.

## ⚠️ Важно про безопасность

Сайт статический — токен бота попадает в исходный код страницы и виден любому. Для этого проекта это допустимо. Если токен случайно утечёт и по нему начнут спамить — просто перевыпустите его в @BotFather (`/revoke` → `/token`) и замените в `index.html`.

## 📝 Изменение контента

Весь сайт в одном файле `index.html`. Тексты, цены, фото — всё в HTML-разметке. Фотографии подгружаются с Unsplash по прямым URL — можно заменить на свои.
